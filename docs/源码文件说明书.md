## 一、程序入口与全局

### 1. Program.cs
- 程序入口：初始化 Avalonia 桌面平台。
- **单实例保护**：`Mutex Global\ScreenshotCollector_SingleInstance`；第二实例启动时依次尝试
  ①`FindWindow` 按标题唤起 → ②按 PID 枚举顶层窗口兜底（ShowWindow + SetForegroundWindow）；
  两者都找不到（已有实例处于"无窗口僵尸状态"、一直占着单实例锁）时**结束无窗口实例并作为新实例接管**，
  杜绝"点了没反应"。

### 2. App.axaml / App.axaml.cs
- 全局样式资源（浅色主题）。
- 启动流程：先显示 `SplashWindow` 启动画面（背景插画 + 圆形 Logo + 「都市天际线 王四季」品牌字样），
  2.5 秒后切换到 `MainWindow` 主窗口；切换用 **DispatcherTimer**（非 async/await，
  游戏等独占前台应用运行时不依赖 SynchronizationContext 恢复，杜绝"卡在启动画面"）；
  **服务先行**：剪贴板/热键/托盘先于窗口显示启动，窗口显示即使被系统阻塞托盘仍可用，不会"假死"。
- **全局异常捕获**：`AppDomain.UnhandledException` 写入日志，避免静默崩溃。

### 3. ScreenshotCollector.csproj
- net8.0 / Avalonia 11.2.4 / CommunityToolkit.Mvvm 8.2.2
- `ApplicationIcon = Assets\Brand\app_icon_pic.ico`（exe 程序图标，原图圆形版）
- NoWarn 含 CA1416（Windows 专用 API 提示关闭）

## 五、Services 后台服务层（独立后台逻辑）

### 1. LogService.cs
- 日志写入 exe 同级 `logs\log_日期.txt`（UTF-8 带 BOM）；
- 自动清理过期日志（保留天数可配，默认 7 天）。

### 2. FileArchiveService.cs
- 归档：`图片库\ScreenshotCollector\分类\日期\时间戳_分类.png`；
- MD5 去重、最小尺寸过滤、重名自动加 `_1` 序号；
- `Archived` 事件回调（**来源原始路径, 归档路径, 分类, 时间**——UI 实时刷新并记录原始路径）。

### 3. FolderWatcherService.cs
- FileSystemWatcher 监控：天际线 `Screenshots`（F12）、编辑器快照 `Snapshots`；
- **Snapshots 递归监听（含 UUID 子目录）**：按文件名前缀分类归档——`snapshot*.png`→编辑器快照、
  `thumbnail*.png`→编辑器缩略图、`tooltip*.png`→编辑器提示图（游戏每次快照生成三个文件）；
- `FolderStatusChanged` 事件 → 状态灯红/黄切换。

### 4. ClipboardCaptureService.cs
- Win32 剪贴板监听：优先 PNG 私有格式，兜底 CF_DIB；
- **前台进程校验**：仅当前台为微信（WeChat.exe / Weixin.exe 4.0 兼容）/QQ 时保存；
- 800ms DispatcherTimer 轮询 + 2 秒冷却防重；启动时先读一次再删临时 png。

### 5. WinClipboard.cs
- 剪贴板读写封装：写入 PNG 私有格式 + CF_DIB 双格式（Avalonia 11
  `CopyPixels(new PixelRect(0,0,w,h), ptr, bufferSize, stride)`，Bgra8888 字节序与 DIB 一致）。

### 6. SocketGameService.cs
- 本地 TCP 23333：接收天际线配套 Harmony 模组推送，一行 JSON `{path,category,time}`；
- 收到快照 → `SnapshotReceived` 事件 → 归档 + 状态灯变绿显示时间；
- 端口被占用时降级返回 false（红灯提示），不崩溃。

### 7. TrayIconService.cs
- 托盘图标（app_icon_pic.ico）+ 右键菜单（打开面板/暂停继续/**隐藏到托盘（后台运行）**/退出）；

### 8. HotkeyService.cs
- WH_KEYBOARD_LL 低级键盘钩子（独立线程）；
- 仅注册「自定义 ≠ 默认」的热键；命中时用 `keybd_event` 模拟原生快捷键转发给系统。

### 9. WindowActivator.cs

### 八.五、游戏 Mono 兼容性规则（模组铁律）

天际线一代运行在 **.NET 3.5 API surface**（Unity Mono），以下用法**全部规避**（每次崩溃均已 IL 级验证修复）：

| 禁用写法 | 原因 | 替代 |
|---|---|---|
| `type == null` | 触发 `Type.op_Equality`（.NET 4.0） | `ReferenceEquals(type, null)` |
| `lock` / `Monitor.Enter` | Mono 环境 Monitor 极不稳定 | ModLog 无锁；Watcher 用 `Interlocked`（.NET 1.1） |
| `Path.Combine`（≥3 参）/ 整个 System.IO.Path | 多参重载是 .NET 4.0；报错消息不带签名易误判 | 手写 `PathUtil.Join/DirName`（.NET 1.x 字符串 API） |
| `TcpClient.ConnectAsync` | .NET 4.5 API | `BeginConnect` + `EndConnect`（.NET 2.0）+ 2s 超时 |
| `System.Func`2` / 显式泛型委托 | .NET 4 把 Func/Action 放 mscorlib，游戏 Mono（.NET 3.5）加载不到 → TypeLoadException | 自定义 `delegate`（.NET 1.x） |
| LINQ（OrderByDescending 等） | lambda 编译成 mscorlib Func`2 引用，同样崩溃 | 手写循环找最新文件 |
| Task/async、System.Text.Json、IsNullOrWhiteSpace、Lazy、Tuple | .NET 4.0+ | 一律不用 |

## 九、关键实现备忘（踩坑记录）

1. Avalonia 11 `IClipboard` 无 `GetImageAsync`（CS1061）→ 用 Win32 剪贴板（WinClipboard）。
2. WPF 的 `WindowStyle` 在 Avalonia 不存在（AVLN2000）→ 用 `SystemDecorations`。
3. Avalonia 无 WPF 式分组集合视图 → 代码分组（ScreenshotGroup + RebuildGroups）。
4. `Bitmap.CopyPixels` 签名：`(PixelRect, IntPtr, int, int)`，无 PixelFormat 参数，Bgra8888 与 DIB 一致。
5. 微信 4.0 进程名为 `Weixin.exe`（旧版 `WeChat.exe`），剪贴板校验需两者兼容。
6. Shell 环境仅 PowerShell（pwsh 7），Bash 禁用；日志文件 UTF-8 带 BOM（python 查验）。
7. 游戏 Mono 是 .NET 3.5 surface：MissingMethodException 消息**不带参数签名**，报"Path.Combine 缺失"
   实际是 **3 参重载（.NET 4.0）** 缺失，2 参调用正常——排查时先看调用处用了哪个重载。
8. `lock` 编译成 `Monitor.Enter`，游戏 Mono 环境不可靠 → 模组彻底无锁化/Interlocked。
9. ICities.dll 无 IExtendedUserMod/IModContent，设置页走 `OnSettingsUI(UIHelperBase)` 鸭子类型反射。
10. 天际线一代快照是 `Snapshots\<UUID>\` 子目录结构（snapshot/thumbnail/tooltip 三个文件）——
    只监听顶层永远收不到，必须 `IncludeSubdirectories=true` 并按文件名前缀分类。
11. Avalonia 11 的 `WrapPanel` **没有** `Spacing` 属性（CS 编译不过，AVLN2000）→ 按钮间距改用 Margin。
12. `System.Func`2` 崩溃（TypeLoadException: Could not load type 'System.Func`2'）：
    .NET 4 把 Func/Action 移进 mscorlib，而游戏 Mono（.NET 3.5 surface）加载不到——
    显式 `Func<T,R>` 参数与 **LINQ lambda（OrderByDescending 等）** 都会引用它；
    改用自定义 `delegate`（.NET 1.x）+ 手写循环（ScreenshotWatcher 已修，IL 验证 Func 引用 0）。
