## 三、ViewModels 视图模型层（MVVM 业务核心）

### 1. BaseViewModel.cs
- 基类，继承 ObservableObject，所有 ViewModel 继承它。

### 2. MainViewModel.cs（根 VM）
- 菜单项集合（MenuItem）、SelectedMenu、MainPage 枚举页面切换；
- `IsListVisible`（列表/设置页切换）、`IsSettingsVisible`、暂停/继续捕获；

- `LoadAllArchived()`：启动时扫描归档目录全部历史截图（按 LastWriteTime 降序，

### 6. MenuItem.cs

## 五、Services 后台服务层（独立后台逻辑）

### 1. LogService.cs
- 日志写入 exe 同级 `logs\log_日期.txt`（UTF-8 带 BOM）；
- 自动清理过期日志（保留天数可配，默认 7 天）。

### 2. FileArchiveService.cs
- 归档：`图片库\ScreenshotCollector\分类\日期\时间戳_分类.png`；
- MD5 去重、最小尺寸过滤、重名自动加 `_1` 序号；
- `Archived` 事件回调（归档成功通知 UI 实时刷新）。

### 3. FolderWatcherService.cs
- FileSystemWatcher 监控：天际线 `Screenshots`（F12）、编辑器快照 `Snapshots`；
- Steam 截图目录自动探测（`Steam\userdata\*\760\remote\255710\screenshots`，未找到则记日志）；
- `FolderStatusChanged` 事件 → 状态灯红/黄切换。

### 4. ClipboardCaptureService.cs
- Win32 剪贴板监听：优先 PNG 私有格式，兜底 CF_DIB；
- **前台进程校验**：仅当前台为微信（WeChat.exe / Weixin.exe 4.0 兼容）/QQ 时保存；
- 800ms DispatcherTimer 轮询 + 2 秒冷却防重；启动时先读一次再删临时 png。

### 5. WinClipboard.cs
- 剪贴板读写封装：写入 PNG 私有格式 + CF_DIB 双格式（Avalonia 11
  `CopyPixels(new PixelRect(0,0,w,h), ptr, bufferSize, stride)`，Bgra8888 字节序与 DIB 一致）。

### 6. SocketGameService.cs
- 本地 TCP 23333：接收天际线配套 Harmony 模组推送，一行 JSON `{path,category,time}`；
- 收到快照 → `SnapshotReceived` 事件 → 归档 + 状态灯变绿显示时间；
- 端口被占用时降级返回 false（红灯提示），不崩溃。

### 7. TrayIconService.cs
- 托盘图标（app_icon_pic.ico）+ 右键菜单（打开面板/暂停继续/退出）；
- 关闭窗口隐藏到托盘；`SetAutoStart` 写 HKCU Run 注册表实现开机自启。

### 8. HotkeyService.cs
- WH_KEYBOARD_LL 低级键盘钩子（独立线程）；
- 仅注册「自定义 ≠ 默认」的热键；命中时用 `keybd_event` 模拟原生快捷键转发给系统。

### 9. WindowActivator.cs
- 唤起指定程序窗口：EnumWindows 查找 + ShowWindow(SW_RESTORE) + SetForegroundWindow；
- 供「分享到微信/QQ」自动把聊天窗口调到前台。

## 八、配套模组工程（mods/CitiesSkylines.ScreenshotLinker）

《城市：天际线》一代本地模组（net46 + ICities.dll），游戏内截图推送端。
完整说明见 `mods/CitiesSkylines.ScreenshotLinker/说明书.md`，结构概要：

| 文件 | 职责 |
|---|---|
| Mod.cs | IUserMod 入口（名称/描述/OnEnabled/OnDisabled） |
| ScreenshotWatcher.cs | 监听 Screenshots（F12）+ Snapshots（编辑器快照）目录，防抖后推送 |
| SocketSender.cs | TCP 客户端 127.0.0.1:23333，一行 JSON（协议与桌面端 SocketGameService 一致） |
| ModLog.cs | 轻量日志（模组 DLL 同级 ScreenshotLinker.log） |
| publish.ps1 | 一键发布到游戏本地模组目录（%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods） |

- 不依赖 Harmony/游戏内部 API（纯 FileSystemWatcher，兼容 5.x 任意版本）；
- 端到端已验证：模拟模组推送 → 桌面端归档 `天际线\日期\时间戳_天际线.png` + 列表实时新增。

## 九、关键实现备忘（踩坑记录）

1. Avalonia 11 `IClipboard` 无 `GetImageAsync`（CS1061）→ 用 Win32 剪贴板（WinClipboard）。
2. WPF 的 `WindowStyle` 在 Avalonia 不存在（AVLN2000）→ 用 `SystemDecorations`。
3. Avalonia 无 WPF 式分组集合视图 → 代码分组（ScreenshotGroup + RebuildGroups）。
4. `Bitmap.CopyPixels` 签名：`(PixelRect, IntPtr, int, int)`，无 PixelFormat 参数，Bgra8888 与 DIB 一致。
5. 微信 4.0 进程名为 `Weixin.exe`（旧版 `WeChat.exe`），剪贴板校验需两者兼容。
6. Shell 环境仅 PowerShell（pwsh 7），Bash 禁用；日志文件 UTF-8 带 BOM（python 查验）。
