## 一、这个项目是什么

一个 **《城市：天际线》游戏截图自动收集工具**，由**两个独立工程**配合完成：

| 工程 | 位置 | 技术栈 | 运行在哪 | 干什么 |
|---|---|---|---|---|
| 游戏内模组 | `mods\CitiesSkylines.ScreenshotLinker` | C# · .NET 3.5 Mono · Harmony | 游戏进程内（加载 DLL） | 监听游戏截图、点击按钮、把截图路径推给桌面工具 |
| 桌面端工具 | `src\ScreenshotCollector` | C# · Avalonia UI · .NET 8 · Win32 | 独立 Windows 程序（.exe） | 接收推送、自动归档截图、界面浏览、托盘/热键等 |

一句话流程：**游戏里按 F12 截图 → 模组感知到 → TCP 推给桌面工具 → 工具自动分类保存到"图片\ScreenshotCollector"并显示在列表里。**

## 四、模组侧源码详解（mods\CitiesSkylines.ScreenshotLinker）

### 4.1 文件清单总表

| 文件 | 类型 | 一句话职责 | 关键点 |
|---|---|---|---|
| `Mod.cs` | 入口 | 模组生命周期的总管 | OnEnabled 起服务、OnSettingsUI 画设置页、LaunchDesktopApp 启动桌面工具 |
| `ScreenshotLinkerConfig.cs` | 配置 | XML 配置读写 | 端口/补丁开关/桌面工具路径(含相对兜底) |
| `PathUtil.cs` | 工具 | 手写路径拼接 | 不用 System.IO.Path，规避游戏 Mono 缺失重载 |
| `ModLog.cs` | 工具 | 写日志 | 写到模组 DLL 同目录 ScreenshotLinker.log |
| `ScreenshotLinkerUI.cs` | UI | 游戏内浮动按钮 | 180×30，左键启动、右键拖拽 |
| `SocketSender.cs` | 通信 | 向桌面工具推 JSON | TCP，2 秒超时，失败静默 |
| `ScreenshotWatcher.cs` | 服务 | 监听截图目录 | FileSystemWatcher + 防抖 + 分类 |
| `Patches\ScreenshotPatch.cs` | 服务 | Harmony 补丁 | 截图保存后"即时"推送给桌面端 |

### 4.2 逐个文件讲清楚

**① Mod.cs —— 模组的"大脑"**
- 实现 `IUserMod` 接口（天际线模组标准入口）。
- `OnEnabled()` 启用时：读配置 → 启动两条捕获通道（Harmony 补丁 + 目录监听）→ 挂载游戏内按钮。
- `OnSettingsUI()` 在游戏"选项 → Mods"里画设置页（端口、补丁开关、监听开关、桌面工具路径、按钮文字、不透明度）。
- `LaunchDesktopApp()`：用配置路径启动桌面 exe；**找不到就走"模组同目录 \ ScreenshotCollectorTool \ ScreenshotCollector.exe"的兜底**（这是发布给玩家能用的关键）。

**② ScreenshotLinkerConfig.cs —— 配置**
- 用 XmlSerializer 把配置存成模组同目录 `ScreenshotLinkerConfig.xml`。
- 关键字段：Port、UseHarmonyPatch、UseFolderWatch、DesktopAppPath、ButtonText、OpacityPercent。
- 特别说明：`GetDesktopAppPath()` 里加了**相对路径兜底**（玩家订阅后自动找到随包分发的工具），这是本次为了对标 RoadBuilder 新增的逻辑。

**③ PathUtil.cs —— 兼容性保护层**
- 因为游戏是旧的 Mono（.NET 3.5 surface），`Path.Combine` 三参重载、`Func`、`Monitor` 等新版 API 会崩。
- 所以全部用 .NET 1.x 的字符串拼接手写：`Join`、`DirName`、`ModDirectory()`。

**④ ModLog.cs —— 日志**
- 写到模组 DLL 同目录 `ScreenshotLinker.log`；写失败兜底到 `%APPDATA%\ScreenshotLinker.log`。
- 刻意无锁（游戏环境不稳），丢了也无所谓，绝不拖垮模组。

**⑤ ScreenshotLinkerUI.cs —— 游戏内按钮**
- 固定 180×30，右上角；左键点击 = 启动桌面工具，右键拖拽 = 移动按钮（纯轮询 Input.mousePosition）。
- 不透明度由设置页控制。

**⑥ SocketSender.cs —— 推送给桌面端**
- `TcpClient` 连 `127.0.0.1:23333`，发一行 JSON：`{"path":"...","category":"天际线","time":"..."}`。
- 2 秒超时，失败返回 false，不抛异常、不影响游戏。

**⑦ ScreenshotWatcher.cs —— 目录监听兜底通道**
- 监听 `%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Screenshots`（F12）和 `Snapshots`（编辑器快照）。
- 新图片出现 → 等写入稳定（防抖）→ 推送给桌面端。
- 分类：天际线 / 编辑器快照 / 编辑器缩略图 / 编辑器提示图。

**⑧ Patches\ScreenshotPatch.cs —— Harmony 补丁通道（即时）**
- Harmony 2.x Postfix 无参签名，补丁 `Game.ScreenshotManager.TakeScreenshot`，保存完成后立刻 `PushLatest`。
- 补丁没命中就静默降级到目录监听，不影响功能。

## 六、两者通信协议（一句话讲清）

- 端口：`127.0.0.1:23333`（模组侧叫 SocketSender，工具侧叫 SocketGameService，端口可在设置里改）。
- 协议：**一行 JSON + 换行**：
  ```
  {"path":"D:\\...\\1.png","category":"天际线","time":"2026-10-23T12:00:00"}
  ```
- category 取值：`天际线` / `编辑器快照` / `编辑器缩略图` / `编辑器提示图`（模组推送分类，工具据此归档）。
- 特点：发送 2 秒超时、失败静默；工具侧收到即归档并触发界面刷新。

## 七、数据与日志都放哪（重要，别把数据写进游戏/工具包）

| 数据 | 位置 | 说明 |
|---|---|---|
| 工具归档截图 | `图片\ScreenshotCollector\`（MyPictures） | 可改，设置页可换目录 |
| 工具设置 | `%LOCALAPPDATA%`（LocalApplicationData） | 进程级配置 |
| 工具日志 | exe 同级 `logs\log_yyyyMMdd.txt` | 保留 7 天 |
| 模组日志 | 模组 DLL 同目录 `ScreenshotLinker.log` | 兜底 %APPDATA% |
| 模组配置 | 模组 DLL 同目录 `ScreenshotLinkerConfig.xml` | 玩家在游戏设置页改 |

> 设计意图：**用户数据一律放在 AppData/图片目录，不放模组/工具包内**，这样 Steam 更新模组时不会把用户数据清掉。

## 八、关键技术决策（为什么这么写）

1. **游戏侧全部用 .NET 1.x/2.x 最基础 API**：游戏是 Mono (.NET 3.5)，`Path.Combine` 三参、`Func`、`Monitor`、`ConnectAsync` 等新版 API 会崩或 MissingMethodException → 于是手写 PathUtil、自定义委托、用 Interlocked/ThreadPool。
2. **双通道保障**：Harmony 补丁（即时）+ 目录监听（兜底），补丁失败也不影响。
3. **工具侧是独立单文件 exe**：Avalonia + .NET 8 自包含发布，玩家免装运行时。
4. **单实例 + 僵尸进程接管**：防止多开重复抓图/端口冲突；无头僵尸实例会被结束并接管。
5. **启动路径相对兜底**：桌面工具随模组包分发（ScreenshotCollectorTool\），玩家订阅后按钮可直接启动（对标 RoadBuilder）。

## 九、如何编译与发布（简短）

### 9.1 编译模组
```
dotnet build "mods\CitiesSkylines.ScreenshotLinker\CitiesSkylines.ScreenshotLinker.csproj" -c Release
```
- 依赖游戏 DLL：`D:\SteamLibrary\...\Cities_Data\Managed\ICities.dll / UnityEngine.dll / ColossalManaged.dll`
- 输出会按 csproj 直接放到本地测试模组目录 `Addons\Mods\CitiesSkylines.ScreenshotLinker\`

### 9.2 编译桌面工具
在 `src\ScreenshotCollector` 用 VS 发布（win-x64 自包含单文件），产物到 `publish\ScreenshotCollector-win-x64\ScreenshotCollector.exe`。

### 9.3 打工坊包
- 脚本：`publish\Workshop_Package\build_workshop_package.bat`（双击即重新打包）
- 结构：`CitiesSkylines.ScreenshotLinker.dll + CitiesHarmony.Harmony.dll + ScreenshotCollectorTool\ScreenshotCollector.exe`
- 详见同目录 `打包与发布说明.txt`。
