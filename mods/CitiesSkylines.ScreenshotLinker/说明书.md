# 模组源码说明书：CitiesSkylines.ScreenshotLinker

> 更新日期：2026-10-23
> 配套桌面端：ScreenshotCollector（截图自动收集器，TCP 23333 接收端）

---

## 一、模组是什么

《城市：天际线》一代（Steam 5.6.7 最终版）本地模组。作用：游戏内 **F12 截图** 和 **编辑器快照**
生成后，通过本地 TCP 23333 端口把图片路径实时推送给桌面端「截图自动收集器」，
实现 **即时归档到"天际线/编辑器快照"分类** + **桌面端 🚥 状态灯变绿联动**。

## 二、与桌面端的分工

| 端 | 职责 |
|---|---|
| 桌面端（ScreenshotCollector） | 监听目录 + 剪贴板 + Socket 接收 + 归档 + 界面展示 |
| 本模组（游戏内） | 只做一件事：截图生成 → 推送一行 JSON（不复制文件、不落盘） |

桌面端本身也会监听截图目录（双保险），本模组推送的价值：
1. **即时性**：文件落盘瞬间推送，无需等待文件系统事件；
2. **状态灯联动**：桌面端收到推送后「天际线模组」状态灯变绿并显示最近快照时间；
3. 为后续扩展（如游戏内快捷键、快照元信息）预留通道。

重复兜底：同一张图若被桌面端目录监听先归档，模组推送再触发时会命中 **MD5 去重**，不会重复保存。

## 三.五、内容管理器显示与设置页

- **内容管理器列表只显示模组名称**「截图自动收集器联动（ScreenshotLinker）」（Description 置空，不显示描述块）；
- **设置功能在游戏「选项 → Mods」页签**：通过模组类上的 `OnSettingsUI(UIHelperBase helper)` 方法
  （游戏反射鸭子类型调用，天际线一代标准做法，无需额外接口）；
- 设置项：
  - **桌面端端口**（文本框，默认 23333，提交后保存）；
  - **启用 Harmony 补丁**（开关，截图瞬间即时推送）；
  - **启用目录监听兜底**（开关，任何情况都能推送）；
  - 「保存配置」按钮。
- 配置存 `ScreenshotLinkerConfig.xml`（模组 DLL 同目录），修改即时保存，**重启模组生效**。

## 四、Harmony 框架说明

采用**工坊 Harmony 2 模组同款框架结构**（参考 `D:\SteamLibrary\steamapps\workshop\content\255710\2040656402\`，
即"CitiesHarmony.Harmony.dll（HarmonyLib）+ 模组 DLL 随包携带"）：

1. **双通道推送**：
   - **通道1（Harmony 补丁）**：`new Harmony(HarmonyId)`（HarmonyLib）初始化 → 反射探测
     `Game.ScreenshotManager.TakeScreenshot`（程序集 Assembly-CSharp），命中即补丁，
     Postfix 触发时把最新截图立即推送（时机早于文件事件）；
   - **通道2（目录监听兜底）**：FileSystemWatcher 监听官方截图目录，补丁未命中也能推送。
2. **类名/方法名不硬编码**：反射探测，找不到自动降级，绝不让游戏崩溃。
3. **Postfix 无参数签名**：与原方法签名零耦合，不会因签名不匹配报错。
4. **随包自带 CitiesHarmony.Harmony.dll**：不需要用户额外订阅工坊 Harmony，装本模组即用；
   若用户已启用工坊 Harmony 2（2040656402），游戏复用同名程序集、零冲突。
5. **卸载安全**：OnDisabled 调用 `UnpatchAll` 移除全部补丁。

### ⚠️ 游戏 Mono 兼容性（重要踩坑，已修复）

天际线一代运行环境是 **.NET 3.5 API surface**（Unity Mono），以下 .NET 4.x API **不存在**，
曾导致加载崩溃，现均已规避：

| 崩溃点 | 原因 | 修复 |
|---|---|---|
| `type == null` | 触发 `Type.op_Equality`（.NET 4.0 才引入）→ MissingMethodException | 改为 `ReferenceEquals(type, null)` |
| `lock (obj)` / `Monitor.Enter` | 游戏 Mono 的 Monitor.Enter 极不稳定（曾连续报 Method not found） | **彻底移除 Monitor/lock**：ModLog 无锁（AppendAllText + catch），ScreenshotWatcher 用 `Interlocked`（.NET 1.1 API）|
| `Path.Combine(a, b, c)`（≥3 参） | 3/4 参/params 重载是 .NET 4.0 才加入，游戏 Mono 只有 2 参 → MissingMethodException（报错消息不带签名，易误判为整个 Path 缺失） | **彻底移除 System.IO.Path 依赖**：新增 `PathUtil.cs`（Join/DirName 全手写，仅用 .NET 1.x 字符串 API），IL 级验证零 Path 调用 |
| `TcpClient.ConnectAsync` | .NET 4.5 才引入，运行时会 MissingMethodException | 改为 `BeginConnect` + `EndConnect`（.NET 2.0 API）+ 2 秒超时 |

规则：**模组代码禁用所有 .NET 4.0+ 专属 API 与一切 Monitor/lock/System.IO.Path**——lock 语句、
Type 运算符重载（== 判空）、Path.Combine 多参重载、Task/async、ConnectAsync、System.Text.Json、
IsNullOrWhiteSpace、Lazy、Tuple 等；判空一律 `ReferenceEquals`，线程同步一律 `Interlocked`（int 标志），
路径一律手写 `PathUtil.Join/DirName`。

## 五、技术要点

1. **防抖**：Created 事件可能触发多次/文件未写完——后台线程每 500ms 采样文件大小，
   尺寸连续两次相同才推送（最长等 5 秒）。
2. **连接超时 2 秒**：桌面端未启动时快速失败，绝不影响游戏性能。
3. **协议**（与桌面端 SocketGameService 完全一致）：
   ```
   {"path":"D:\\...\\20261023_123456.png","category":"天际线","time":"2026-10-23T12:34:56"}
   ```
   - category：`天际线`（Screenshots 目录）/ `编辑器快照`（Snapshots 目录）
   - time 用 ISO 格式 `yyyy-MM-ddTHH:mm:ss`（桌面端 System.Text.Json 的 TryGetDateTime 只接受 ISO）
4. **日志**：`ScreenshotLinker.log` 写在模组 DLL 同目录，游戏内排查用。

## 七、验证链路（端到端）

1. 先启动桌面端 ScreenshotCollector.exe（日志出现「天际线模组通信已启动（端口 23333）」）；
2. 游戏内按 F12 截图（或编辑器快照）；
3. 期望：
   - 模组日志 `ScreenshotLinker.log`：`推送成功：xxxx.png（天际线）`
   - 桌面端日志：`已归档：...\天际线\2026-10-23\xxxx_天际线.png（来源 天际线）`
   - 桌面端左栏「天际线模组」状态灯变绿并显示最近快照时间；
   - 中栏列表实时新增该截图。

## 八、已知限制

- 桌面端未运行时推送失败（静默，游戏不受影响），下次截图再试即可；
- 旧存档/无目录时会 60 秒重试等待截图目录创建；
- 目前仅覆盖官方 Screenshots/Snapshots 目录，Steam 云截图目录由桌面端单独探测。
